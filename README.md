## 🖥️ 프레젠테이션 조작 방법
* **`→` / `←` 또는 `Space`**: 슬라이드 이동
* **`F` 키**: 전체 화면(Full Screen) 모드
* **`O` 키**: 전체 슬라이드 타일 뷰 (Overview)
* **`S` 키**: 발표자 노트 및 타이머 창 (Speaker View)
